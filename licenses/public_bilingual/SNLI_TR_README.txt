SNLI-TR 1.1

Thank you for your interest in our dataset.  The only difference between SNLI-TR 1.1 and SNLI-TR 1.0 is that the former one includes an extra field, namely "translation_annotations". This README file will include the notes regarding the cosmetic changes which don't effect its version.
